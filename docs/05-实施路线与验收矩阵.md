## 3. 无 USB-RS485 时的退化验收路径

A-06 / A-11 需要 PC 接入 RS485 总线。**当前未持有该配件**，因此：

| 原验收项 | 退化替代 | 强度损失 |
|---|---|---|
| A-06 双路交叉比对 | **B-06**：B 板 TFT 显示 `temp_limit/uptime` → 同时看 MQTT 收到的同字段；A 板串口打 `0x111` 原始 8 字节 hex，人工/脚本三方比对 | 从"两条独立自动路"降为"一路自动 + 一路人工读屏"。核心风险（投影错、刻度错、字节序错）仍可捕获，但捕获靠人 |
| A-11 双路改配置等价 | **B-11**：只用 MQTT `cmd` 路 + B 板本地按键路（按键也走 `MB_REG_SetHolding`+`Slave_ApplyConfigChange`），比对 24C02 落盘结果 | 未覆盖"RS485 写入"这一路。该项在拿到 USB-RS485 后必须补做，脚本已预留 `--require-rs485` 门禁 |
| RS485 协议回归 | `Tools/python/run_tests.py` 离线 `LoopbackTransport`（**已在 v2.0 证明可 11/11 通过**）+ 双板 A↔B 直接对拼（M1 拓扑，A 板主站轮询 B 板从站） | 无损失。M1 拓扑本身就是 RS485 双节点实测 |

**结论**：RS485 与 CAN 两条总线在任何形态下都是**真机双板实测**，损失的只是"PC 作为第三方观测者插进 RS485 总线"的能力。
一只 USB-RS485（或 TTL↔RS485 小板 + 已有 USB 串口线）即可解锁 A-06/A-11 全自动化 —— 这是本项目**唯一的采购建议**。

> **07 号文档修订后的补充**：原先把 USB-RS485 视为"让 RS485 段闭环"的必要条件，**该结论已作废**。
> 现在 A 板与 B 板自身就构成 RS485 主/从两端（A: USART2/PD5,PD6 主站；B: USART2/PD5,PD6 从站），
> RS485 段**无需任何外部设备即可闭环并做真机验收**。USB-RS485 的用途**收窄为两件事**：
> ① PC 作为第三方观测者做 A-06 双路交叉比对；② PC 仿真现场 PLC/仪表做 A-11。
> 即：**没有它系统仍可完整运行与验收；有它则验收自动化程度提升。**
> 另外 §2 表中 A-12 的"M1 拓扑"字样（上文 §2 待确认项与 §3 表中的"形态"表述）一律按 07 §5 的统一拓扑理解。

## 4. 故障注入清单（v0.8 执行）

| 注入 | 期望行为 | 观测点 |
|---|---|---|
| 拔 RS485 A/B 线 30 s | `mb_timeout` 递增、`comm_ok=0`、LED2 绿 120 ms 闪（连败 ≥3）、B 板从站无异常、`0x111.status=2` | A 板 counters 主题 |
| 短接 CANH-CANL 3 s | bus-off → 指数退避 → 自恢复；期间遥测缺失但**不复位** | `can_bo`、`event` 主题 |
| 停 mosquitto 60 s | 透传检测断连 → 重连退避 → 补发 | `lk` bit3、`event 10`、`seq` 连续性 |
| 断 Wi-Fi（关 PC 热点） | 同上，但 AT 状态机停在 `WIFI_JOIN`，不得进 `PASS_THRU` | `lk` bit2、`at_state` |
| ESP-12F 掉电（拔模块） | `at_window` 超时 → 全量 RESET → 重试；期间 CAN/Modbus 不受影响 | A 板 TFT 监控页 |
| B 板断电重启 | A 板 3 s 内判 `0x501` 心跳丢 → `event 9`；B 板回来后 `event 8` + 重新镜像 | `lk` bit1 |
| A 板拔 CAN | B 板本地采集/日志/按键改参数**照常工作**（离线自治要求） | B 板 TFT + 24C02 |
| 写 RO 寄存器 0x05 | 异常 0x02，`mb_exception`++，B 板 `errcode=2` | `status."er"` |
| 写超量程 0x09=0 | 异常 0x03（`MB_REG_ValidateConfigValue` 拒 0），**不落盘** | 24C02 内容不变 |
| 灌坏 CRC 帧（`pressure_test --mix`） | 静默丢弃、`crc_err`++、无响应、无异常码 | A-03/A-13 |
| 人为 `vTaskDelay` 阻塞 T2 5 s | IWDG ≤ 3 s 复位 + `task_ovr`++ + 上电 `LOG_BOOT` 事件带复位原因 | 复位计数 |

**离线自治是硬要求**：A 板完全掉线时，B 板必须继续采集、显示、按键改参数、写日志。
这条决定了 B 板不能依赖 A 板授时或授权 —— 契约把权威存储放在 B 板正是为此（02 号文档 §2）。
