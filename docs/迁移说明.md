## 6. v0.1 剩余工作（按依赖顺序）

1. **`BSP/bsp_w25q128.c` 改用 SPI2**：把硬编码的 SPI1/PA4-PA7 换成 `FLASH_SPI_PERIPH` /
   `FLASH_SPI_AF` / `FLASH_*_PORT/PIN` 宏，并加上电 `FLASH_EXPECTED_JEDEC` 校验（`docs/07 §6`）。
2. **`Core/Inc/stm32g4xx_hal_conf.h` 取并集**：现缺 `HAL_FDCAN_MODULE_ENABLED`、`HAL_IWDG_MODULE_ENABLED`
   （CAN 侧有）、`HAL_UART_MODULE_ENABLED`（Modbus 侧为寄存器级 USART 驱动故未开）。
3. **`Core/Src/stm32g4xx_hal_msp.c`**：把 `HAL_FDCAN_MspInit` 由
   `GPIOB PIN_12|13 + GPIO_AF9_FDCAN2` 改为 `GPIOD PIN_0|1 + GPIO_AF9_FDCAN1`（用 `CAN_*` 宏）；
   新增 `HAL_USART2_MspInit` / `HAL_USART3_MspInit` / `HAL_SPI2_MspInit`。
4. **`Core/Src/stm32g4xx_it.c`**：增加 `FDCAN1_IT0_IRQHandler`、`USART2_IRQHandler`、`USART3_IRQHandler`。
5. **`Core/Src/main.c` 合并**：并入 CAN 侧的外设初始化（FDCAN2 → 按宏、IWDG）与
   `CAN_Task` / `App_HandleRx` 调度；保持 M1/M2 与角色分支。
6. **新建 `Common/bsp_printf.c/.h`**：从 CAN 侧 `bsp_uart.c` 的 `BSP_UART_Printf` 提取，
   改为 per-task 缓冲池（`CONSOLE_TX_BUF_LEN` × `CONSOLE_TX_POOL_NUM`）+ 互斥，
   替换 v3.0 的 96 B 单静态缓冲（非重入）。
7. **合并 `BSP/bsp_led`**：取 CAN 侧的 BSRR 状态驱动实现 + Modbus 侧的 API 面；保持 `LED1_PIN/LED2_PIN`。
8. **`MDK-ARM/G474.uvprojx` 建 4 Target**（`A_GW_M1/A_GW_M2/B_NODE_M1/B_NODE_M2`），
   加角色守卫 `#if`，并验证 `CAN_USE_FDCAN=2` 回退也能编过。
9. **UV4 批处理全绿**：`D:\U5\UV4\UV4.exe -b` 逐个 Target，产出 `MDK-ARM/build_check.log`，
   要求 0 error / 0 warning，然后删除 `App/app_board_cfg.h` 顶部的 `V01_MIGRATION_INCOMPLETE` 哨兵。
