# 02 板级硬件配置（bsp_board_cfg）

> 依据 Genbotter STM32G474VET6 开发板背面丝印整理。
> 所有硬件差异收敛到唯一头文件 `BSP/bsp_board_cfg.h`，任何引脚变更只改此文件。

## 1. 引脚分配总表

| 功能          | 引脚    | 说明                                   |
|---------------|---------|----------------------------------------|
| RS485 数据    | PB10/PB11 | USART3：TX=PB10, RX=PB11（丝印 485_RX/485_TX 为端子视角，电学上以 AF 表为准，见 §3） |
| WiFi 复用     | PB10/PB11 | 与 RS485 共用同一 USART3（丝印 WIFI_TX/WIFI_RX），本项目不使用 |
| CAN           | PB12/PB13 | FDCAN1（丝印 CAN_RX=PB12/CAN_TX=PB13），本项目不使用 |
| LED 蓝        | PE0       | 低电平点亮（例程已证）                 |
| LED 绿        | PE1       | 低电平点亮                             |
| 按键 WKUP     | PA0       | 确认/保存                              |
| 按键 K0       | PA2       | 下一项                                 |
| 按键 K1       | PA3       | 修改                                   |
| 24C02         | PA15(SCL)/PB9(SDA) | I2C1（丝印 I2C1_SCL_PA15, I2C1_SDA_PB9） |
| W25Q128       | PA4(CS)/PA5(SCK)/PA6(MISO)/PA7(MOSI) | SPI1 |
| LCD           | PD11(CS)/PB3(SCL)/PB5(SDA)/PD12(DC)/PD13(BL) | 与 SPI1 主引脚组不同，疑似软件 SPI（待确认 LCD 型号与接口方式） |
| RTC 电池      | —        | CR1220，日志时间戳可选用 RTC           |

## 2. 待确认项（直接影响代码的开关）

| # | 事项 | 影响 | 当前默认 |
|---|------|------|----------|
| 1 | RS485 是否有 DE/RE 方向控制引脚（板上是否自动收发电路） | bsp_rs485 是否做 GPIO 方向切换 | 默认"无 DE 引脚=自动收发"，代码保留 `RS485_USE_DE_PIN` 开关，可一键切到 GPIO 控制 + TC 等待模式 |
| 2 | LCD 型号/控制器（ST7789/ILI9341/SSD1306…）与接口（硬件 SPI 还是软 SPI） | bsp_lcd 底层实现 | 先提供接口与占位实现，确认后填充 |
| 3 | 485 收发器是板上集成还是外接模块，A/B 端子位置 | 无（协议层无关） | — |

**验证方法（第 1 项）**：用万用表量 485 收发器（如 SP3485/MAX485）的 DE/RE 是否直连 TXD
反相电路（自动收发）或悬空需外接；或查阅卖家原理图。若板上有 485 端子且仅需 2 线（A/B），
通常为自动收发电路。

## 3. 引脚复用说明（USART3）

STM32G474 的 AF 复用表中，PB10 仅可作 USART3_TX(AF7)，PB11 仅可作 USART3_RX(AF7)。
因此无论丝印如何标注，MCU 侧电学事实为：

```
USART3_TX = PB10   → 接 485 收发器 DI（发送数据进入收发器）
USART3_RX = PB11   ← 接 485 收发器 RO（总线数据回到 MCU）
```

丝印"485_RX 接 PB10 / 485_TX 接 PB11"是端子/模块视角命名（模块的 RX 脚接 MCU 的 TX），
编程时不需理会，按 USART3 默认映射即可。

## 4. 板级配置宏草案（bsp_board_cfg.h）

```c
/* 节点角色 */
#define MODBUS_NODE_ROLE_MASTER   0
#define MODBUS_NODE_ROLE_SLAVE    1
#ifndef MODBUS_NODE_ROLE
#define MODBUS_NODE_ROLE          MODBUS_NODE_ROLE_SLAVE   /* 默认从站 */
#endif

/* RS485: USART3 */
#define RS485_UART                 USART3
#define RS485_UART_CLK_ENABLE()    __HAL_RCC_USART3_CLK_ENABLE()
#define RS485_TX_GPIO_Port         GPIOB
#define RS485_TX_PIN               GPIO_PIN_10
#define RS485_RX_GPIO_Port         GPIOB
#define RS485_RX_PIN               GPIO_PIN_11
#define RS485_AF                   GPIO_AF7_USART3

/* DE/RE 方向控制：未知时置 0（自动收发）；有引脚时置 1 并填引脚 */
#define RS485_USE_DE_PIN           0
#if RS485_USE_DE_PIN
#define RS485_DE_GPIO_Port         GPIOA
#define RS485_DE_PIN               GPIO_PIN_8
#endif
```

## 5. LED / 按键（例程已核实）

| 丝印 | 引脚 | 极性 |
|------|------|------|
| BLUE | PE0  | 低电平点亮 |
| GREEN| PE1  | 低电平点亮 |

按键在 `bsp_key.c` 中实现短按/长按/消抖，WKUP=PA0 需注意其具备唤醒功能，普通读取即可。
