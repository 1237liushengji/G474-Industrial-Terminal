# 06 测试计划与验收标准

## 1. 测试环境

```
PC ──USB-UART── A板(Master 固件) ──RS485(A/B)── B板(Slave 固件)
        │                                              │
        └─────────(可选: USB-UART 直连任一板)───────────┘
```

- 上位机：`Tools/python/modbus_tool.py`（pyserial）
- 辅助：逻辑分析仪/示波器抓 A/B 差分波形与 DE 时序（有 DE 时）
- 版本基线：每次测试记录 Git 版本号

## 2. 正常功能测试

| # | 用例 | 步骤 | 期望 |
|---|------|------|------|
| N1 | 0x01 读线圈 | read 01 0 4 | 返回 1 字节，与板上 LED 状态一致 |
| N2 | 0x03 读保持 | read 01 0 5 | 温度/湿度/电压/电流/状态正确缩放显示 |
| N3 | 0x06 写单个 | write 01 40010 350 | 回显；读回 350；LCD 阈值更新 |
| N4 | 0x10 写多个 | write_multi 01 40010 4 | 回执 start/qty；逐个读回一致 |
| N5 | 0x04 输入寄存器 | (V1.1) read 30001 | 返回 ADC/温度/VREFINT |
| N6 | 0x05 写线圈 | (V1.1) coil_write 01 1 1 | 板上 LED 点亮/熄灭 |
| N7 | 统计增长 | 连续读 100 次后读 40007/40008 | RX=TX=100(±广播), CRCErr=0 |

## 3. 异常/健壮性测试

| # | 用例 | 注入方式 | 期望 |
|---|------|----------|------|
| E1 | 非法功能码 | 发 01 0F ...(0x0F 不支持) | 异常 01 8F 01 |
| E2 | 非法地址 | 03 起始 0x0100 | 异常 01 83 02 |
| E3 | 数量越界 | 03 0x000E qty=5 | 异常 01 83 02 |
| E4 | 非法数据值 | 06 写 40010 数量.../写只读 40001 | 异常 01 86 02 或 03 |
| E5 | CRC 错误 | 篡改帧末 CRC | 无响应；从站 CRCError++；日志记录 |
| E6 | 长度错误 | 帧缺字节 | 无响应（帧超时丢弃）；不崩溃 |
| E7 | 帧间隔破坏 | 字节间插入 >t1.5 间隙 | 判为两帧/超时丢弃，不误响应 |
| E8 | 错误 SlaveID | 发 02 03 ... | 无响应（静默丢弃） |
| E9 | 从站断电 | 运行中拔 B 板电源 | Master 超时→重试 2 次→报故障；恢复后自愈 |
| E10 | 485 断开 | 拔 A/B 线 | 同 E9 超时路径；插回恢复 |
| E11 | 电压/温度越阈值 | 改阈值触发 | DeviceStatus/ErrorCode 变化 + 日志 |

## 4. 压力测试（v1.3，脚本化）

- `pressure 10000`：连续 0x03 读 10000 帧（qty=5）
  统计：TX=10000，成功=10000，丢失=0，CRC错=0（允许在脚本中打印进度）。
- 混合压力：读/写/异常轮换 5000 帧。
- 长时间稳定性：1 小时 @100ms 周期（≥36000 帧）不掉线，计数器无异常跳变。
- 结果输出 JSON/文本存档 `Tools/python/results/`。

## 5. 存储与掉电测试

| # | 用例 | 步骤 | 期望 |
|---|------|------|------|
| P1 | 参数保存 | 改 TempLimit/VoltageLimit/SlaveID/Baudrate | 写 24C02 成功 |
| P2 | 掉电恢复 | 断电→上电 | 参数与保存值一致（CRC 校验通过） |
| P3 | 数据损坏 | 人为写坏 EEPROM 区（工具注入） | 启动检测 CRC 失败→加载默认值+日志 |
| P4 | 日志写满 | 循环产生错误事件填满 W25Q128 | 环形覆盖最旧记录，读回最新记录正确 |

## 6. LCD/按键（v1.0+）

- 首页数值与寄存器一致；K0 切页；K1 修改；WKUP 确认；保存后 LCD 提示。
- 错误页显示 CRC/TIMEOUT/EXCEPTION 计数。

## 7. PC 工具测试

- 全部命令 help/read/write/write_multi/coil_read/coil_write/monitor/pressure 可用；
- monitor 原始帧输出可人工核对 CRC；工具与固件 CRC 交叉验证一致。
