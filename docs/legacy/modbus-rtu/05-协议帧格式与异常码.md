# 05 Modbus 协议帧格式与异常码

> 依据 Modbus 应用协议规范 V1.1b3，仅实现 RTU 模式、功能码 0x01/0x03/0x06/0x10（+0x04/0x05 扩展可选）。

## 1. RTU 帧结构

```
[SlaveAddr:1B][Function:1B][Data:N B][CRC16_Lo:1B][CRC16_Hi:1B]
```

- CRC16-Modbus：多项式 0x8005（反射 0xA001），初值 0xFFFF，
  帧中低字节在前。算法自研实现于 `Protocol/modbus_crc.c`（查表 + 逐位两版，PC 单测互证）。
- 帧间静默 ≥ t3.5，帧内字节间隔 < t1.5（见状态机文档 §2.1）。

## 2. 功能码帧格式

### 0x01 读线圈 Read Coils
请求：`[addr][0x01][start:2][qty:2][crc]`
响应：`[addr][0x01][byteCount][coilData...][crc]`，qty∈[1,2000]，本系统线圈 4 个。

### 0x03 读保持寄存器 Read Holding Registers
请求：`[addr][0x03][start:2][qty:2][crc]`，qty∈[1,125]
响应：`[addr][0x03][byteCount=2*qty][regHi regLo ...][crc]`

### 0x06 写单个寄存器 Write Single Register
请求：`[addr][0x06][regAddr:2][value:2][crc]`
响应：**回显请求帧**（原样返回）

### 0x10 写多个寄存器 Write Multiple Registers
请求：`[addr][0x10][start:2][qty:2][byteCount][regHi regLo ...][crc]`
响应：`[addr][0x10][start:2][qty:2][crc]`

### 0x04 读输入寄存器 Read Input Registers（扩展，V1.1）
请求：`[addr][0x04][start:2][qty:2][crc]`，响应同 0x03。

### 0x05 写单个线圈 Write Single Coil（扩展，V1.1）
请求：`[addr][0x05][coilAddr:2][0xFF00|0x0000][crc]`
响应：回显请求帧。线圈值 0xFF00=ON，0x0000=OFF。

## 3. 异常响应

异常帧：`[addr][0x80|func][exceptionCode][crc]`

| 异常码 | 名称                  | 触发场景                                  |
|--------|-----------------------|-------------------------------------------|
| 0x01   | Illegal Function      | 功能码不支持(如 0x05/0x0F 在 V1.0)        |
| 0x02   | Illegal Data Address  | 起始地址+数量越界；写只读区                |
| 0x03   | Illegal Data Value    | 数量=0/超上限；byteCount 不匹配；0x10 写线圈/只读；值非法 |
| 0x04   | Slave Device Failure  | 执行失败（预留：如 EEPROM 写失败）         |

请求处理管线（从站）：

```
帧 → CRC通过 → 地址匹配 → 功能码在支持集?
        │是                          │否 → 0x01
        ▼
   地址/数量/数据合法性检查 ── 非法 → 0x02 / 0x03
        │ 合法
        ▼
   执行读写/参数更新 → 失败 → 0x04（预留）
        ▼
   组正常响应（CRC 附尾）→ RS485 发送
```

> 广播地址 0x00：从站接收并执行但**不响应**（V1.0 预留，暂不启用广播写入）。

## 4. 主站请求队列（任务表）

主站支持任务化请求（`master_task_t`），任务表示例：

```c
typedef enum {
    MB_TASK_READ_TEMP,      /* 03 40001 qty2 */
    MB_TASK_READ_VOLT,      /* 03 40003 qty2 */
    MB_TASK_READ_STATUS,    /* 03 40005 qty5(状态+错误+统计) */
    MB_TASK_WRITE_LIMIT,    /* 06/10 写阈值（事件触发,非周期） */
    MB_TASK_COUNT
} mb_task_id_t;
```

- 周期任务按 POLL 节拍轮转；写任务由事件（CLI/上位机命令）插入一次性队列。
- 每个任务记录最近结果：ok/timeout/exception + 原始响应缓存（供 monitor 输出）。

## 5. CRC 验证向量（测试用）

| 数据                          | CRC16(Modbus) |
|-------------------------------|---------------|
| `01 03 00 00 00 02`           | `C4 0B`       |
| `01 06 00 09 01 2C`           | 由实现计算并固化到单测 |
| `01 10 ...`（写4寄存器示例）   | 由实现计算    |

Python 侧 `modbus_crc.py` 提供同算法，压力测试时互相比对。

## 6. 通信故障判定（主站）

| 现象                 | 判定                                     | 计数            |
|----------------------|------------------------------------------|-----------------|
| 帧间隔内无响应       | timeout，重试（默认最多 2 次）           | timeout_cnt++   |
| 重试耗尽             | 通信故障（标记），恢复轮询继续尝试        | fail 事件入日志  |
| 响应 CRC 错          | 丢弃，按超时处理（或立即重试）            | crc_error_cnt++ |
| 收到异常响应         | 解析异常码，任务标记 exception            | exception_cnt++ |
| 总线静默(485断开)    | 与超时同路径                              | timeout_cnt++   |
