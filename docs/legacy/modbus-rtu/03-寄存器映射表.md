# 03 寄存器映射表（modbus_register 契约）

> 本表是 Master / Slave / Python 工具 / LCD 显示的**唯一数据契约**。
> 地址列 = 协议 PDU 中的寄存器地址（0x0000 起始）；显示编号列 = 用户习惯的 40001/30001/00001 编号。
> 实现见 `Protocol/modbus_register.c/.h`。

## 1. 保持寄存器 Holding Registers（0x03 读 / 0x06 写单个 / 0x10 写多个）

| 地址 | 编号   | 名称          | 读写 | 单位/分辨率 | 说明                        | 掉电保存 |
|------|--------|---------------|------|-------------|-----------------------------|----------|
| 0x00 | 40001  | Temperature   | RO   | 0.1 ℃       | 当前温度(AD 数据源)         | —        |
| 0x01 | 40002  | Humidity      | RO   | 0.1 %RH     | 当前湿度                    | —        |
| 0x02 | 40003  | Voltage       | RO   | 0.01 V      | 当前电压                    | —        |
| 0x03 | 40004  | Current       | RO   | 0.01 A      | 当前电流                    | —        |
| 0x04 | 40005  | DeviceStatus  | RO   | —           | 设备状态(见状态枚举)        | —        |
| 0x05 | 40006  | ErrorCode     | RO   | —           | 当前错误码(0=无)            | —        |
| 0x06 | 40007  | RXCount       | RO   | 帧          | 从站收到有效请求帧数        | —        |
| 0x07 | 40008  | TXCount       | RO   | 帧          | 从站发送响应帧数            | —        |
| 0x08 | 40009  | CRCErrorCount | RO   | 次          | CRC 错误计数                | —        |
| 0x09 | 40010  | TempLimit     | RW   | 0.1 ℃       | 温度报警阈值                | ✅       |
| 0x0A | 40011  | VoltageLimit  | RW   | 0.01 V      | 电压报警阈值                | ✅       |
| 0x0B | 40012  | SamplePeriod  | RW   | ms          | 采样周期(如 100~10000)      | ✅       |
| 0x0C | 40013  | DeviceMode    | RW   | —           | 工作模式                    | ✅       |
| 0x0D | 40014  | SlaveID       | RW   | —           | 从站地址 1~247              | ✅       |
| 0x0E | 40015  | Baudrate      | RW   | 码表        | 波特率索引(见下)            | ✅       |

寄存器总数（协议可见） = 0x0F 个（15 个），地址范围 [0x00, 0x0E]。

### 波特率码表（40015）

| 值 | 波特率 |
|----|--------|
| 0  | 9600   |
| 1  | 19200  |
| 2  | 38400  |
| 3  | 57600  |
| 4  | 115200 |
| 5  | 230400 |

> 写 40014/40015（SlaveID/波特率）成功后：RAM 立即生效并触发参数保存；
> 波特率/SlaveID 是否需要"重启后生效"由 `CONFIG_APPLY_MODE` 决定，默认立即生效（简单可控）。

## 2. 输入寄存器 Input Registers（0x04 读）

| 地址 | 编号   | 名称        | 说明                      |
|------|--------|-------------|---------------------------|
| 0x00 | 30001  | ADC1        | ADC1 通道原始/换算值      |
| 0x01 | 30002  | ADC2        | ADC2 通道值               |
| 0x02 | 30003  | MCU_Temp    | MCU 内部温度(0.1℃)        |
| 0x03 | 30004  | VREFINT     | 内部参考电压              |

V1.0 未启用 ADC 前，输入寄存器返回模拟/默认值，接口与 ADC 解耦（`device_manager` 提供数据源）。

## 3. 线圈 Coils（0x01 读 / 0x05 写单个）

| 地址 | 编号  | 名称     | 说明                       |
|------|-------|----------|----------------------------|
| 0x00 | 00001 | FAN      | 风扇开关(从站输出)         |
| 0x01 | 00002 | RELAY    | 继电器                    |
| 0x02 | 00003 | LED_BLUE | 板上蓝色 LED（PE0 低有效） |
| 0x03 | 00004 | LED_GREEN| 板上绿色 LED（PE1 低有效） |

线圈数量：4（地址 [0x00, 0x03]），数量参数按"位"打包（0x01 读线圈按字节打包返回）。

## 4. 访问范围与异常映射

| 功能码 | 请求寄存器区         | 越界返回              |
|--------|----------------------|-----------------------|
| 0x01   | Coils [0x00,0x03]    | 0x02 Illegal Data Address |
| 0x03   | Holding [0x00,0x0E]  | 0x02                  |
| 0x04   | Input [0x00,0x03]    | 0x02（V1.1 起启用）   |
| 0x06   | Holding [0x09,0x0E]  | 0x02；只读区写 → 0x02 |
| 0x10   | Holding 写区          | 0x02                  |

- 读功能码支持"起始地址+数量"超出末尾 → 0x02。
- 0x06/0x10 写**只读区**（地址 < 0x09 的测量/统计区）→ 0x02。
- 数量=0 或超出单帧上限（0x10 单帧 123 字节数据）→ 0x03 Illegal Data Value。

## 5. 数据结构（types.h 中的寄存器对象）

```c
typedef struct {
    uint16_t value;
    uint8_t  is_writable;   /* 0=只读 1=可写 */
    /* 扩展：写回调、保存标志等由 modbus_register 内部表管理 */
} modbus_holding_reg_t;
```

寄存器表在 `modbus_register.c` 中静态定义，并提供：

```c
void     MODBUS_REG_Init(void);              /* 从 config 加载参数区 */
uint16_t MODBUS_REG_GetHolding(uint16_t addr);
void     MODBUS_REG_SetHolding(uint16_t addr, uint16_t val);
uint8_t  MODBUS_REG_GetCoil(uint16_t addr);
void     MODBUS_REG_SetCoil(uint16_t addr, uint8_t on);
/* 统计接口由 device_manager 维护并在读取时反映到 40007~40009 */
```

## 6. 一致性约束

- 寄存器地址、数量范围、读写属性：**以本表为准**，代码与文档必须同步修改。
- 40014/40015/40010~40013 的持久化布局见 `docs/06-Storage`（24C02 参数区定义）。
- Python 工具解析显示缩放系数同本表（温度 ×0.1 等），两侧必须一致，由共用常量表保证。
