# 04 状态机与帧时序设计

## 1. 设备总状态机（system_manager）

```
BOOT ──► INIT ──► READY ──► RUNNING ──► CONFIG/ERROR
          │         │          │
          └─────────┴──────────┴──► (故障自恢复回到 RUNNING)
```

| 状态    | 进入条件                     | 行为                                 |
|---------|------------------------------|--------------------------------------|
| BOOT    | 上电                        | 时钟/HAL 初始化                      |
| INIT    | 外设就绪                    | 参数加载(24C02)、日志区打开、LCD 初始化 |
| READY   | 参数校验通过                | 自检完成，等待启动条件               |
| RUNNING | 启动条件满足                | 主循环周期任务：协议处理/轮询/刷新   |
| CONFIG  | 按键进入配置/收到配置命令   | 参数修改界面                         |
| ERROR   | 致命错误                    | 错误码登记 + 日志 + 指示             |

## 2. 从站帧接收状态机（V1.0 中断收字节 + 帧间隔判定）

### 2.1 Modbus 帧时序

- 帧间隔：`t3.5` = 3.5 个字符时间（一个字符 = 1起始+8数据+1停止 ≈ 10 bit）。
  - 9600bps：≈ 3.65 ms；115200bps：≈ 0.304 ms（工程取 350×波特率系数微调）。
- 帧内最大间隔：`t1.5`，超过判帧错误（本设计 V1.0 简化：只要收到字节，超过 t3.5 未见新字节即判"帧完成"，丢弃校验失败的半帧）。
- 实现：USART RX 中断每收到 1 字节 → 存入缓冲 + 重置/启动"帧超时定时器"；
  主循环检查定时器溢出标志 → 进入 `FRAME_COMPLETE`。

### 2.2 从站状态机（Protocol/modbus_slave.c）

```
        ┌─────────── IDLE ◄──────────────────────────┐
        │              │ 收到任意字节                 │
        │              ▼                             │
        │          RECEIVING  ◄──┐ (字节到达, 续帧)    │
        │              │ t3.5超时│                    │
        │              ▼         │                    │
        │       FRAME_COMPLETE   │                    │
        │              │                             │
        │              ▼                             │
        │         ADDR_CHECK（≠本机/广播→丢帧回 IDLE）│
        │              │                             │
        │              ▼                             │
        │          CRC_CHECK ── 失败→ CRCError++ → 日志 → IDLE
        │              │ 通过                         │
        │              ▼                             │
        │          FUNCTION_DISPATCH（功能码分派）     │
        │              │                             │
        │              ▼                             │
        │         EXECUTE / BUILD_EXCEPTION           │
        │              │                             │
        │              ▼                             │
        │            SEND_RESPONSE（RS485_TX，CRC 附尾）│
        └──────────────┴─────────────────────────────┘
```

状态集合（`types.h` 中枚举 `mb_slave_state_t`）：
`SLAVE_IDLE / SLAVE_RECV / SLAVE_FRAME_READY / SLAVE_CRC_OK / SLAVE_PROCESS / SLAVE_RESPOND / SLAVE_TX_DONE`

### 2.3 帧超时定时

- 使用一个硬件定时器（如 TIM6）作 1 ms 节拍，或 SysTick 计数；
  帧超时阈值按波特率换算为毫秒（见 §2.1），波特率变更时重算。

## 3. 主站状态机（Protocol/modbus_master.c）

```
 POLL ──► SEND_REQUEST(组帧+CRC, RS485_TX)
              │
              ▼
        WAIT_RESPONSE(超时定时=timeout)
         │                      │
     收到帧                    超时
         │                      │
         ▼                      ▼
   CRC/功能码校验            RETRY(计次)
     │通过   │失败            │次数<max
     ▼       ▼(丢弃,超时化)    ▼
 UPDATE_DATA  ◄────────── RETRY_SEND
     │                        │次数≥max
     ▼                        ▼
    POLL ◄───────────────── FAIL(记录错误+统计)
```

| 状态            | 说明                                    |
|-----------------|-----------------------------------------|
| MASTER_IDLE     | 空闲/等待轮询节拍                      |
| MASTER_POLL     | 取出下一条请求（读/写/配置）            |
| MASTER_SEND     | 组帧发请求，进入等待                    |
| MASTER_WAIT     | 等响应，软件定时器超时                  |
| MASTER_SUCCESS  | 响应校验通过 → 更新数据/统计 → 下一任务 |
| MASTER_RETRY    | 重试（重发同一请求）                    |
| MASTER_TIMEOUT  | 超过重试上限 → 标记通信故障             |

主站参数（可配置，`config` 结构体）：
- 单次响应超时：默认 100 ms（115200bps 下从站响应 << 1ms，余量充足）
- 最大重试次数：默认 2（共发 3 次）
- 轮询周期：默认 500 ms 一轮（读温度/湿度/电压/电流 + 状态）

## 4. 统计计数器（主从共有，从站映射到 40007~40009）

| 计数器        | 含义                   | 从站寄存器 |
|---------------|------------------------|------------|
| tx_count      | 已发送帧               | 40008      |
| rx_count      | 已接收有效帧           | 40007      |
| crc_error_cnt | CRC 错误帧             | 40009      |
| timeout_cnt   | 超时(主站)             | —          |
| retry_cnt     | 重试次数(主站)         | —          |
| exception_cnt | 收到的异常响应(主站)   | —          |

主站可另把统计映射到本机保持寄存器供上位机读取（扩展区 0x40+ 保留）。

## 5. LCD 刷新节拍（V1.0，从站）

- 500 ms 刷新一次首页数据；按键进入 CONFIG/ERROR 页。
- 首页显示：SlaveID/波特率/温度/湿度/电压/收发统计/状态（格式见 README 或 v1.0 文档）。
